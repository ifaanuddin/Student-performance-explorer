# Student Performance Explorer

A beginner Data Science project exploring student performance using Python and Pandas.

## Goals

- Explore student performance data
- Calculate basic statistics
- Create visualizations
- Learn the fundamentals of Git and GitHub

## Dataset

The dataset contains student study hours, attendance, and scores in Mathematics, Science, and English.
